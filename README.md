# Prototypes

A public collection of UI/web prototypes built by an AI Application Engineer.
Live at **prototypes.genkitec.com**

---

## English

A gallery of small, self-contained web prototypes — each exploring a different industry, interaction pattern, or design language. The index itself supports three languages (JA / EN / ZH) and light/dark themes out of the box.

### Prototypes included

| # | Name | Category |
|---|------|----------|
| 01 | Nogami Salon | Hair Salon landing + reservation |
| 02 | Okumiya Co., Ltd. | Real Estate & Financial Planning |

### Stack

- Vanilla HTML / CSS / JavaScript — no build step, no framework
- Hosted on GitHub Pages with a custom domain via CNAME

### Local preview

Open `index.html` directly in a browser — no server required.
